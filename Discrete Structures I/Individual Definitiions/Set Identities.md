## Table 4.8.1: Set Identities

| Name                      | Identities                                                                                                                                     | Plain English                                                                    |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **Idempotent laws**       | $A \cup A = A$ <br><br> $A \cap A = A$                                                                                                         | Combining a set with itself changes nothing.                                     |
| **Associative laws**      | $(A \cup B) \cup C = A \cup (B \cup C)$ <br><br> $(A \cap B) \cap C = A \cap (B \cap C)$                                                       | Grouping doesn't matter.                                                         |
| **Commutative laws**      | $A \cup B = B \cup A$ <br><br> $A \cap B = B \cap A$                                                                                           | Order doesn't matter.                                                            |
| **Distributive laws**     | $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$ <br><br> $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$                                     | Union distributes over intersection, and vice versa.                             |
| **Identity laws**         | $A \cup \emptyset = A$ <br><br> $A \cap U = A$                                                                                                 | Union with nothing, or intersection with everything, changes nothing.            |
| **Domination laws**       | $A \cap \emptyset = \emptyset$ <br><br> $A \cup U = U$                                                                                         | Intersection with nothing gives nothing; union with everything gives everything. |
| **Double complement law** | $\overline{\overline{A}} = A$                                                                                                                  | Negating twice returns the original set.                                         |
| **Complement laws**       | $A \cap \overline{A} = \emptyset$ <br><br> $A \cup \overline{A} = U$ <br> <br> $\overline{U} = \emptyset$ <br> <br> $\overline{\emptyset} = U$ | A set and its complement are disjoint and cover everything.                      |
| **De Morgan's laws**      | $\overline{A \cup B} = \overline{A} \cap \overline{B}$ <br><br> $\overline{A \cap B} = \overline{A} \cup \overline{B}$                         | Complementing swaps union and intersection.                                      |
| **Absorption laws**       | $A \cup (A \cap B) = A$ <br><br> $A \cap (A \cup B) = A$                                                                                       | Combining a set with its union or intersection with another set changes nothing. |
| **Set subtraction law**   | $A - B = A \cap \overline{B}$                                                                                                                  | Keep elements in $A$ that aren't in $B$.                                         |
